# 狼人杀会员系统

Vue 3 + TypeScript 前端、Node.js API 和独立 MySQL 数据库，支持会员管理、月卡与次卡转换、对局记录、玩家出勤、账号登录及手机访问。

应用源码和启动说明见 [frontend/README.md](frontend/README.md)。设计文件与原始参考图保存在项目根目录及 `设计图/` 中。

本地账号、数据库密码、登录会话、数据库数据、依赖和构建产物均不上传；部署时参考 [环境变量示例](frontend/.env.example) 配置。

AWS 自动部署和线上入口见 [deploy/README.md](deploy/README.md)。
